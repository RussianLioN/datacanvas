# Decisions

Версия процесса: 0.1.0

## DEC-S10-001

Решение: result template остается `planned` и `not_started` до принятия `PROC-007`.

Причина: подготовка эксперимента не должна неявно разрешать сетевой provider.

## DEC-S10-002

Решение: rollback является обязательным полем результата эксперимента.

Причина: controlled experiment без rollback path не является безопасным процессным изменением.
