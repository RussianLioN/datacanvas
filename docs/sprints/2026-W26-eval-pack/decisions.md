# Decisions

Версия процесса: 0.1.0

## DEC-S7-001

Решение: не подключать внешний LLM provider в default flow до появления базового eval pack.

Причина: без eval pack невозможно отличить полезное AI-поведение от случайного или небезопасного результата.

## DEC-S7-002

Решение: считать prompt-injection leakage из входных instructions блокирующей ошибкой.

Причина: входной пакет другого агента является недоверенной границей.
