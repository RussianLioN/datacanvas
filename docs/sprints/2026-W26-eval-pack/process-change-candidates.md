# Process Change Candidates

Версия процесса: 0.1.0

## PROC-CANDIDATE-S7-001

Предложение: любой новый LLM provider должен добавлять или обновлять eval cases до включения в default flow.

Причина: provider меняет качество, latency, стоимость и failure modes.

Статус: candidate for retrospective.

## PROC-CANDIDATE-S7-002

Предложение: каждый eval case должен ссылаться на requirement, risk или ADR.

Причина: eval backlog должен быть трассируемым, а не набором произвольных тестов.

Статус: candidate for retrospective.
