# Decisions

Версия процесса: 0.1.0

## DEC-S34-001

Решение: runtime state fixture является контрактом сохранения состояния, а не доказательством настоящей пользовательской сессии.

Причина: real UAT требует участия человека и отдельного artifact.

## DEC-S34-002

Решение: валидатор сверяет transition history с `human-review-flow.json`.

Причина: состояние review должно быть управляемым, а не произвольным JSON.
