# Process Change Candidates

## PCC-S25-001: Operational Readiness В Definition Of Done

Кандидат: добавить `npm run validate:ops-readiness` в обязательный DoD для product increments, которые затрагивают LLM, export, render, storage или пользовательский review flow.

Статус: принято как validation gate текущего процесса; отдельный PCR нужен после командной ретроспективы, если gate окажется слишком тяжелым для маленьких increments.
