# Planning

Версия процесса: 0.1.0

## Контекст

S21 оставил следующий безопасный шаг: добавить machine-readable backlog registry. План требует отдельные backlog-контуры, но часть из них существовала только косвенно.

## Scope

В scope входят:

- `backlog-registry.json`;
- schema backlog registry;
- Technical Backlog;
- Eval Backlog;
- validator;
- ADR;
- подключение к gates и audit.

Вне scope:

- полноценная система управления backlog items;
- синхронизация с Kaiten;
- автоматический парсер Markdown backlog-таблиц.
