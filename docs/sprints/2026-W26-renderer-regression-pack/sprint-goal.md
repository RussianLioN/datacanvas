# Sprint Goal: Renderer Regression Pack

Цель инкремента: добавить renderer regression pack для HTML/PDF/PNG outputs, связанный с source spec, render result и export smoke gates.

Done when:

- regression manifest генерируется автоматически;
- validator проверяет HTML/PDF/PNG cases;
- gate подключен к `npm test` и CI;
- ограничения smoke fixtures явно зафиксированы.
