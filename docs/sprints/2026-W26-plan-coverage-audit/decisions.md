# Decisions

Версия процесса: 0.1.0

## DEC-020-001

Покрытие плана фиксируется в JSON и Markdown.

Причина: JSON нужен для проверок, Markdown нужен для командного review.

## DEC-020-002

Наличие `partial` в audit является основанием не закрывать активную цель.

Причина: цель требует реализации всего плана, а не только текущих process gates.
