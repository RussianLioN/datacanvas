# Process Change Candidates

Версия процесса: 0.1.0

## Candidate

Добавить правило: перед завершением крупной goal-работы должен существовать coverage audit с явным статусом по каждому разделу source plan.

## Метрика Успеха

Goal не помечается complete, пока audit содержит `partial` или `not_started` по DoD-критичным разделам.
