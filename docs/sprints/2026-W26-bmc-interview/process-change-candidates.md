# Process Change Candidates

## PCR Candidate

Если BMC-интервью станет повторяемым способом discovery для всех ИТ-продуктов, создать `PROC-*` для правила:

- начинать интервью с выбора режима;
- сохранять ответы и evidence отдельно;
- маркировать claims без evidence как `unconfirmed`;
- генерировать BMC views из trace contract.

Текущая имплементация является product discovery increment, а не изменением общего процесса.
