# Decisions

Версия процесса: 0.1.0

## DEC-S15-001

Решение: failure-rate budget violation должен давать rollback decision.

Причина: provider reliability является stop-rule для controlled experiment.

## DEC-S15-002

Решение: typed risk traceability должен сверяться с основной traceability matrix.

Причина: отдельные risk artifacts не должны расходиться с requirements evidence.
