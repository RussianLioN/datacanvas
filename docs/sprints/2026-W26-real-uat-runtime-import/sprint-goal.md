# Sprint Goal

Подготовить проверяемый import gate для real UAT runtime state, чтобы команда могла безопасно создать `human-review-session-real.json` после реальной пользовательской сессии.

## Ожидаемый результат

- Есть manifest формата импорта.
- Есть CLI-validator readiness/import.
- Есть русская инструкция для команды.
- Процесс не принимает fixture как real UAT evidence.
