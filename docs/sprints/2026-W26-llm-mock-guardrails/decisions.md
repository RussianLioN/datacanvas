# Decisions

Версия процесса: 0.1.0

## DEC-S6-001

Решение: использовать локальный mock adapter как обязательный первый контур LLM boundary.

Причина: это сохраняет воспроизводимость, снижает риск нестабильных тестов и позволяет развивать контракты до подключения реальной модели.

## DEC-S6-002

Решение: считать неподтвержденный `FACT-*` блокирующей ошибкой.

Причина: DataCanvas должен генерировать проверяемые презентации, а не свободные утверждения без трассировки к исходным данным.

## DEC-S6-003

Решение: сетевые вызовы запрещены в default test path.

Причина: базовый контур должен быть безопасным, быстрым и воспроизводимым в локальной среде и CI.
