# Decisions

Версия процесса: 0.1.0

## DEC-018-001

Artifact registry проверяется отдельным скриптом, а не только JSON Schema.

Причина: JSON Schema не проверяет существование путей, последовательность ID и связь `sprint_id` с evidence-манифестом.

## DEC-018-002

Пропуски в `ART-*` запрещены.

Причина: последовательный реестр проще ревьюить, ссылаться в evidence и проверять на случайные удаления.
