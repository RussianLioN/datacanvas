# Process Change Candidates

## PCC-S24-001: Hash Gate Для Всех Registry-Артефактов

Кандидат: включить `npm run validate:artifact-hashes` в обязательный Definition of Done для process и product increments.

Причина: registry без hash gate подтверждает наличие файлов, но не фиксирует их содержимое.

Статус: принято через текущий validation gate, отдельный PCR не требуется до командной ретроспективы.
