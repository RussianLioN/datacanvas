# Planning

## Sprint Goal

Сделать следующий шаг после real UAT воспроизводимым: команда должна понимать, какие входы нужны для pilot, какие outputs обязательны и какие stop conditions блокируют acceptance.

## Scope

В scope входит только readiness/handoff. Реальный pilot run, `pilot-report.md` и `pilot-process-portability-notes.md` не создаются без внешнего запуска.
