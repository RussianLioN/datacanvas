# RCA

Здесь фиксируются разборы корневых причин для повторяющихся дефектов, сбоев процесса, событий безопасности и регрессий качества.

RCA не закрывается, пока не создано предотвращающее действие: задача в списке работ, проверка, чек-лист, изменение DoR/DoD или запрос на изменение процесса.
