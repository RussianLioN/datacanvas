# 2026-09-04: преждевременное принятие PNG-рендера PlantUML

Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Знания](../README.md) / [RCA](README.md) / Преждевременное принятие PNG-рендера PlantUML

## Контекст

При каскадном обновлении пользовательских историй `CO-2026-003` — заявки на
изменение заказа презентации из агента «Справка по клиенту» — были изменены
исходники PlantUML для диаграмм задержки и успеха после повтора. По договору
производные SVG и PNG должны обновляться только штатным генератором.

## Симптом

После запуска генератора часть PNG-рендеров получила существенно меньший размер
файла. Базовая проверка пропустила эти файлы, потому что видела корректную
PNG-сигнатуру и не проверяла момент завершения записи рендера.

## Корневая причина

Генератор считал файл готовым сразу после появления начальной PNG-сигнатуры и
затем сам завершал процесс PlantUML. Это создавало окно, в котором файл уже
выглядел как PNG, но PlantUML ещё не успел гарантированно завершить запись.

Дополнительный фактор: локальная системная команда Java на macOS оказалась
заглушкой без установленной среды выполнения. Поэтому первый запуск генератора
не мог быть использован как доказательство качества рендера.

## Исправление

- Генератор теперь ждёт завершения процесса PlantUML с успешным кодом выхода.
- Проверка готовности файла выполняется после завершения процесса, а не по
  первому появлению сигнатуры PNG.
- Добавлен отрицательный тест: искусственный медленный PNG-писатель сначала
  создаёт корректную сигнатуру PNG, затем дописывает содержимое. Тест доказывает,
  что рендерер не принимает ранний неполный файл.
- После изменения PlantUML-исходников все диаграммы переведены в состояние
  «кандидат на отдельную приёмку диаграмм», не понижая статус принятого текста
  пользовательских историй.

## Профилактика

- Не обновлять манифест диаграмм без свежего рендера из PlantUML-исходников.
- Не считать наличие PNG-сигнатуры достаточным доказательством готовности
  визуального производного файла.
- При изменении PlantUML-исходника запускать профильную проверку диаграмм
  последовательности и тест преждевременного PNG.
- Если локальная Java недоступна, использовать только локальную среду выполнения
  Java и локальный PlantUML jar; не отправлять содержимое диаграмм во внешний
  веб-сервис.
