# Глоссарий DataCanvas

Навигация: [DataCanvas](../../README.md) / [Документация](../README.md) / [База знаний](README.md) / Глоссарий

| Термин | Определение | Статус |
|---|---|---|
| DataCanvas | ИИ-агент для подготовки редактируемой презентации из проверенного контекста, полученного от пользователя, вызывающего агента или доменного источника | draft |
| КМ | Клиентский менеджер; основной пользователь DataCanvas в клиентских сценариях подготовки презентации | active |
| CSM | Customer Success Manager, роль по сопровождению клиента; если в документе речь идет о клиентском менеджере DataCanvas, используется сокращение `КМ` | draft |
| Лиса | Чатовая поверхность, через которую пользователь может обратиться к DataCanvas, ответить на уточнения и проверить описание будущей презентации | active |
| Вызывающий агент | Другой агент или автоматизированный маршрут, который передает DataCanvas подготовленный контекст и задачу на изготовление презентации | active |
| Оркестратор | Механизм маршрутизации, который связывает DataCanvas с другими агентами, доменными источниками и каналами выполнения задачи | active |
| Vision | Видение продукта; человекочитаемый источник смысла о пользователях, проблеме, решении, ценности и границах продукта | active |
| BMC | Business Model Canvas, бизнес-модель продукта из девяти классических блоков | active |
| MVP | Minimum Viable Product, минимально полезное ядро продукта для проверки основной ценности | draft |
| UX | User Experience, пользовательский опыт взаимодействия с продуктом | draft |
| Редактируемый файл презентации | Итоговый файл, который пользователь получает по электронной почте и может самостоятельно открыть и изменить в редакторе презентаций | active |
| Generated artifacts | Производные артефакты, которые нельзя править вручную; их обновляют только через утвержденные генераторы | active |
| Process Backlog | Отдельный backlog изменений процесса разработки | active |
| Process Change Request | Управляемый запрос на изменение процесса | active |
| Sprint Evidence Pack | Набор доказательств результата спринта | active |
| PresentationSpec | Структурный контракт презентации между ИИ-частью и renderer — модулем отрисовки | draft |
| Claim Map | Связь утверждений на слайде с исходными фактами и источниками | draft |
