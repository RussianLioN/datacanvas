Навигация: [DataCanvas](../../README.md) / [Документация](../README.md) / [Выпуск](README.md) / Скачать браузерный прототип

`CO-2026-003` — согласованное изменение сценария заказа презентации из агента
«Справка по клиенту». Скачайте [ZIP-архив чистового браузерного прототипа](../../artifacts/delivery/co-2026-003-browser-native-phone-prototype.zip?raw=1).

После скачивания распакуйте архив и откройте его корневой `index.html` в
обычном браузере. В архиве находятся все 11 принятых экранов, письмо, девять
страниц презентаций 4K, шрифт и лицензия; сеть и исходные PDF не требуются.

Полный [архив поставки CO-2026-003](co-2026-003-prototype-delivery-archive.md)
остаётся отдельным комплектом проектной документации и доказательств. Он не
заменяет короткий архив для просмотра прототипа.
