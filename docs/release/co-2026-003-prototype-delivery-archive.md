# Архив поставки прототипа CO-2026-003

Навигация: [DataCanvas](../../README.md) / [Документация](../README.md) / [Release](README.md) / Архив поставки прототипа CO-2026-003

## Назначение

Этот архив передаёт самостоятельный комплект материалов `CO-2026-003` — изменение профиля Q4_2026 для Лисы: согласованные решения, требования, путь пользователя, доказательства проверок и переносимый прототип. Его состав задан [машиночитаемым контрактом](co-2026-003-prototype-delivery-archive-contract.json).

> **Статус текущего ZIP-файла.** Существующий ZIP и его доказательства —
> исторический выпуск. Они не подтверждают пять выбранных для будущего
> прототипа формулировок из
> [реестра выбранных текстов](../product/analysis/presentation-link-lisa-user-journey/owner-approved-texts.md)
> и не могут быть выданы как новый выпуск. Новый архив будет собран только
> после выполнения порядка ниже.

> **Граница принятия черновика.** [Дополнение к реестру решений](../product/change-orders/co-2026-003-authoritative-interview-decision-register.md) фиксирует два разных результата: `CO3-AMND-001` — текущие форматы `PPTX` и `PDF`; `CO3-AMND-002` — принятие изолированного черновика только для документального каскада. Поэтому договор архива намеренно не допускает сборку, пока оба статуса выпуска в договоре пути не будут отдельно подтверждены владельцем после каскада.

Общий архив главной цепочки документации не включает этот прототип. Такое разделение не позволяет несогласованному визуальному выпуску задерживать обновление общей документации.

## Обязательная последовательность

1. Владелец продукта принял тексты и все 11 кадров изолированного черновика. Реестр выбранных текстов и манифест черновика фиксируют это только как основание для документального каскада.
2. Для мобильных кадров Лисы и письма текст заменён в существующих SVG-группах с сохранением оформления; для трёх вариантов презентации готовые PDF штатно преобразованы в PNG без пересборки текста и макета. Данные ООО «Водолей Трейд» заменяют данные ГК Достовалова только в источниках мобильных кадров.
3. Изолированная копия прототипа сохраняет оболочку и навигацию исторической демонстрации, но не заменяет её. Черновой PNG не увеличивается для чистового выпуска.
4. Выполняется каскадное обновление решений, требований, историй, BA/SA, спецификаций, трассировки, выпускной документации, навигации и контрольных манифестов.
5. После успешного каскада Владелец отдельно подтверждает переход к чистовому выпуску.
6. Только после этого из тех же согласованных SVG и PDF штатно создаются PNG высокого разрешения, переносимый прототип и его манифест.
7. Проверка пути пользователя и браузерные доказательства подтверждают актуальность и целостность прототипа; обновляется человекочитаемый отчёт доказательств выпуска.
8. Только после успешной проверки собирается архив поставки, затем обновляются навигация, манифесты хэшей и контроль утечек по архивам.

Для этой поставки историческая рабочая книга от 2026-07-08 исключается из
первичных материалов. В архив явно включаются очищенная рабочая книга от
2026-08-17 и её файл происхождения: это согласованный источник истины по срокам
и ресурсам Q4_2026.

Машиночитаемая матрица трассировки также исключается только из этого архива:
она содержит служебные строки контроля утечек и не нужна получателю для
проверки поставки. Полная трассировка остаётся в репозитории и проходит
отдельную проверку.

Обратный порядок запрещён: архив не может включать старый прототип и не может заменять его проверку.

## Текущее состояние

Исторический выпуск был принят для предыдущего состава экранов. Новый
изолированный черновик принят только для документального каскада. Поэтому
штатная генерация действующего прототипа, обновление доказательств и сборка
нового ZIP-файла поставки заблокированы до завершения каскада и отдельного
итогового подтверждения Владельца.

После приёмки сначала применяются команды прототипа и доказательств в точном порядке: `npm run generate:presentation-link-lisa-user-journey`, затем `npm run update:presentation-link-lisa-user-journey:evidence` и `npm run validate:presentation-link-lisa-user-journey:profile`. Если после первого шага изменён любой исходник, договор, генератор или производный файл прототипа, последовательность повторяется с первого шага: нельзя собирать архив по снимкам или отчёту от предыдущего кандидата. Только после успешной профильной проверки применяются команды из контракта архива поставки: `npm run generate:co-2026-003-delivery-archive`, `npm run check:co-2026-003-delivery-archive` и `npm run validate:co-2026-003-delivery-archive`.
