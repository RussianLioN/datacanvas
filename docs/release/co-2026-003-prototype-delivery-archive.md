# Архив поставки прототипа CO-2026-003

Навигация: [DataCanvas](../../README.md) / [Документация](../README.md) / [Release](README.md) / Архив поставки прототипа CO-2026-003

## Назначение

Этот архив передаёт самостоятельный комплект материалов `CO-2026-003` — изменение профиля Q4_2026 для Лисы: согласованные решения, требования, путь пользователя, доказательства проверок и переносимый прототип. Его состав задан [машиночитаемым контрактом](co-2026-003-prototype-delivery-archive-contract.json).

Общий архив главной цепочки документации не включает этот прототип. Такое разделение не позволяет несогласованному визуальному выпуску задерживать обновление общей документации.

## Обязательная последовательность

1. Владелец продукта отдельно принимает содержание и визуальный выпуск пути пользователя.
2. Обновляется канонический источник пути пользователя; все десять исходных экранов остаются в исходном порядке, а экраны ошибочных статусов добавляются после отображения презентаций.
3. Штатный генератор одним выпуском создаёт переносимый прототип и его манифест.
4. Проверка пути пользователя и браузерные доказательства подтверждают актуальность и целостность прототипа.
5. Обновляется человекочитаемый отчёт доказательств выпуска.
6. Только после успешной проверки собирается архив поставки и проверяется его точный состав.
7. Затем обновляются навигация, манифесты хэшей и контроль утечек по архивам.

Для этой поставки историческая рабочая книга от 2026-07-08 исключается из
первичных материалов. В архив явно включаются очищенная рабочая книга от
2026-08-17 и её файл происхождения: это согласованный источник истины по срокам
и ресурсам Q4_2026.

Машиночитаемая матрица трассировки также исключается только из этого архива:
она содержит служебные строки контроля утечек и не нужна получателю для
проверки поставки. Полная трассировка остаётся в репозитории и проходит
отдельную проверку.

Обратный порядок запрещён: архив не может включать старый прототип и не может заменять его проверку.

## Текущее состояние

Владелец продукта отдельно одобрил содержание и визуальный выпуск. Поэтому
разрешены штатная генерация прототипа, проверка его свежести и сборка ZIP-файла
поставки; архив обязан включать именно заново сформированный прототип.

После согласования сначала применяются команды прототипа и доказательств: `npm run generate:presentation-link-lisa-user-journey`, `npm run update:presentation-link-lisa-user-journey:evidence` и `npm run validate:presentation-link-lisa-user-journey:profile`. Затем применяются команды из контракта архива поставки: `npm run generate:co-2026-003-delivery-archive`, `npm run check:co-2026-003-delivery-archive` и `npm run validate:co-2026-003-delivery-archive`.
