# Архивный снимок черновика CO-2026-003

Навигация: [DataCanvas](../../README.md) / [Документация](../README.md) / [Выпуск](README.md) / Архивный снимок черновика CO-2026-003

Этот архив — самостоятельный комплект актуальной документации и черновика прототипа ООО «Водолей Трейд». Он предназначен для работы над документальным каскадом и не является чистовой поставкой.

В архив входят действующие основные документы проектной цепочки, актуальные документы `CO-2026-003`, принятый автономный черновик из 11 кадров и машинные источники, необходимые для воспроизведения проверки состава. Сырые PDF, прежняя демонстрация, исторический переносимый архив, исторические доказательства и архив чистовой поставки исключены.

Сборка допускается только при сохранении запрета на переключение действующего выпуска, чистовой рендер и архив поставки. Манифест внутри ZIP связывает все члены архива самостоятельным отпечатком SHA-256.
