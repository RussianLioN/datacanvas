# Roadmap v0.1

Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Продукт](../README.md) / [Roadmap](README.md) / Roadmap v0.1

## Порядок Поставки

| Этап | Ожидаемый результат | Gate |
|---|---|---|
| Этап 0 | Процесс ведения проектной документации готов к управляемым изменениям. | G0/G1 |
| Этап 1 | Vision, BMC и продуктовые гипотезы согласованы как основа для требований. | G2 |
| Этап 2 | Пользовательские истории, бизнес-требования, критерии приемки и трассировка согласованы между собой. | G3 |
| Этап 3 | Входной контекст для запуска DataCanvas описан и проверяется до подготовки результата. | G4 |
| Этап 4 | DataCanvas формирует редактируемый файл презентации из проверенных и нормализованных данных. | G5 |
| Этап 5 | Пользователь получает файл презентации по согласованному каналу доставки. | G6 |
| Этап 6 | Качество, безопасность и воспроизводимость результата подтверждаются проверками. | G7/G8 |
| Этап 7 | MVP flow — минимальный рабочий маршрут — принят через пользовательскую проверку. | G9 |
| Этап 8 | Pilot — пилотное применение — подтверждает переносимость процесса и готовность к дальнейшему развитию. | G10/G11 |
