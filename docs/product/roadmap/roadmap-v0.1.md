Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Продукт](../README.md) / [Roadmap](README.md) / Roadmap v0.1

## Порядок Поставки

| Этап | Плановый период | Ожидаемый результат | Gate |
|---|---|---|---|
| Этап 0 | Подготовка процесса | Процесс ведения проектной документации готов к управляемым изменениям. | G0/G1 |
| Этап 1 | Подготовка продукта | Vision, BMC и продуктовые гипотезы согласованы как основа для требований. | G2 |
| Этап 2 | Подготовка требований | Пользовательские истории, бизнес-требования, критерии приемки и трассировка согласованы между собой. | G3 |
| Этап 3 | Приоритет `P1`; срок уточняется после оценки команды | Основной запуск DataCanvas другим агентом проходит путь от проверенного входного контекста до подготовки результата без дополнительного подтверждения пользователя. | G4/G5 |
| Этап 4 | Приоритет `P1`; срок уточняется после оценки команды | Пользователь получает редактируемый `PPTX`-файл и нередактируемую `PDF`-копию по электронной почте. | G6 |
| Этап 5 | Приоритет `P2`; срок уточняется после оценки команды | Доставка результата расширяется: появляется защищенная `PDF`-копия по ссылке, ссылка возвращается вызывающему агенту, а пользователь видит уведомление и ссылку в Лисе. | G6/G7 |
| Этап Q4_2026 | Q4_2026 | Пользователь Лисы оформляет один заказ; адреса определяются через «Профиль сотрудника», `ODT` и `PDF` доставляются по электронной почте, а состояние возвращается в тот же чат. | G6/G7 |
| Будущий объем после Q4_2026 | Срок не определен | Системный PUSH, отдельное хранилище, ссылка на файл и расширенное редактирование структуры рассматриваются только после нового решения Product Owner. | отдельный gate |
| Этап 6 | Проверка качества | Качество, безопасность и воспроизводимость результата подтверждаются проверками. | G7/G8 |
| Этап 7 | Пользовательская проверка | MVP flow — минимальный рабочий маршрут — принят через пользовательскую проверку. | G9 |
| Этап 8 | Пилотное применение | Pilot — пилотное применение — подтверждает переносимость процесса и готовность к дальнейшему развитию. | G10/G11 |
