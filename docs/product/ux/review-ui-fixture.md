# Review UI Fixture

## Назначение

Fixture показывает минимальный интерактивный экран проверки DataCanvas для G9 MVP Gate. Он связывает слайды, утверждения, источники, решение ревью и готовность export.

## Что Проверяется

- У каждого утверждения есть trace/source evidence.
- Export доступен только после состояния `approved`.
- Decision log фиксирует действие, роль и источник.
- UAT result подтверждает `accepted`.
- Ограничения candidate видны отдельно.

## Ограничение

Это статический HTML fixture. Он не заменяет настоящую пользовательскую UAT-сессию и не сохраняет изменения в runtime.
