# DataCanvas BMC Source Excerpts

Статус: `partial_source_lock`

Этот файл фиксирует очищенные выдержки для BMC-интервью. Источники ветки `codex/datacanvas-stories-doc` были доступны при предыдущем read-only просмотре, но на момент имплементации ref не найден в текущем checkout. Поэтому связанные утверждения можно использовать для вопросов интервью и гипотез, но не как окончательно подтвержденные факты.

## Доступные Локальные Источники

- `docs/product/vision/vision-v0.1.md`: DataCanvas генерирует короткую проверяемую презентацию из структурированного пакета данных другого агента.
- `docs/product/requirements/user-stories.md`: текущий локальный baseline содержит `US-001`, `US-002`, `US-003`.
- `docs/product/bmc/bmc-v0.1.md`: первичный BMC-черновик с 9 блоками без evidence/status на уровне claims.

## Snapshot Из Готового Vision

- DataCanvas помогает клиентским менеджерам и другим сотрудникам получать рабочие презентации из данных, собранных через Лису, агентов, инструменты и доменные источники.
- Пользователь запускает подготовку презентации в диалоге, уточняет недостающие данные, проверяет описание будущей презентации до генерации и получает итоговый файл по электронной почте.
- Основной пользователь: КМ, клиентский менеджер.
- Участники сценария: пользователь, Лиса, Оркестратор, DataCanvas, другие агенты и инструменты, доменные источники знаний, электронная почта.
- OnePage является историческим образом или примером результата, но не отдельным продуктом и не ограничением для Vision.

## Snapshot Из Готового Каталога Stories

- Канонический каталог содержит 22 stories `DC-ST-01` - `DC-ST-22`.
- MVP-фокус: описание презентации, уточняющие вопросы, выбор формата/шаблона и получение файла по email.
- P1 stories: `DC-ST-01` - `DC-ST-04`.
- P2 stories: `DC-ST-05` - `DC-ST-09`.
- Открытые решения: формат файла, правила выбора получателя, каталог шаблонов, versioning исправлений, контракт входного пакета, поведение при конфликтующих данных.

## Правило Использования

Если пользователь не предоставляет evidence во время интервью, связанный claim сохраняется, но получает статус `unconfirmed` или `assumption`. Такой claim нельзя выдавать как подтвержденный факт.
