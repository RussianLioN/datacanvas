# BMC Interview Artifacts

Эта папка хранит governed artifacts для BMC-интервью DataCanvas.

## Правило

- `*-interview-answers.json` хранит ответы.
- `*-user-evidence.json` хранит метаданные evidence, предоставленного пользователем.
- `*-bmc-interview-results.json` хранит структурированный итог.
- `*-bmc-interview-results.md` хранит читаемый итог для команды.
- `*-evidence-requests.md` хранит запросы evidence по неподтвержденным claims.

Ответ пользователя не является evidence сам по себе. Если evidence отсутствует, связанный claim получает статус `unconfirmed`.

## Текущий Baseline

Файлы `2026-W26-*` являются подготовленным baseline для первого пользовательского интервью. Они не утверждают, что реальное интервью уже проведено.
