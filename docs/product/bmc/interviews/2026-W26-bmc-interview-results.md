# DataCanvas BMC Interview Results

Статус: `completed`

Интервью проведено с реальным пользователем в Codex-чате. Этот artifact фиксирует итоговую сводку интервью; статусы проверки, запросы evidence и пункты для исследования вынесены в companion/evidence JSON.

## Режим

- Выбранный режим: `light`
- Ожидаемая длительность: 30 минут
- Нижняя планка качества: все 9 BMC-блоков, evidence status, список неподтвержденных claims, отдельный итоговый artifact.

## Принятые Решения

| ID | Решение | Статус |
|---|---|---|
| BMC-DEC-001 | BMC-интервью проводится по одному вопросу за раз в Codex-чате. | accepted |
| BMC-DEC-002 | Если пользователь не предоставляет evidence, связанный claim остается неподтвержденным или допущением. | accepted |
| BMC-DEC-003 | Чистовой BMC и рендер не показывают статусы доверия; companion JSON хранит проверки и исследования. | accepted |

## Покрытие BMC

|---|---|---|
| B1 | Сегменты: КМ, CSM, перспективно пользователи Лисы. | требуется проверка |
| B2 | Ценность: быстрее получить рабочую презентацию, снизить ручное копирование и согласовать описание до генерации. | требуется проверка |
| B3 | Каналы: Лиса, выбранные сообщения, кнопка запуска, Оркестратор/A2A, прямой A2A/MCP-вызов и сервисный вызов от АС. | требуется проверка |
| B4 | Отношения: уточняющие вопросы, human-in-the-loop, подтверждение описания, правки и повторный цикл после доставки. | требуется проверка |
| B5 | Потоки внутренней пользы: экономия времени, снижение ручной работы, повторное использование и бюджетный контур. | допущение |

| B8 | Партнеры: Лиса, Оркестратор, предшествующие агенты, поставщики данных, АС, A2A/MCP gateway, владельцы шаблонов и renderer. | требуется проверка |
| B9 | Издержки: LLM-вызовы, renderer, human review, задержка, сопровождение, интеграции, шаблоны, эксплуатация и инциденты. | допущение |

## Evidence Requests

| ID | Claim | Что запросить |
|---|---|---|
| EVD-REQ-001 | B1/B2 | Подтверждение целевого пользователя и боли: интервью, решение команды или user story. |
| EVD-REQ-002 | B3/B4 | Подтверждение каналов и human-in-the-loop flow. |
| EVD-REQ-003 | B5 | Метрики или оценки времени, качества и стоимости review. |
| EVD-REQ-004 | B8 | Владельцы партнерских систем и интеграционные ограничения. |
| EVD-REQ-005 | B9 | Базовые оценки LLM/rendering/support/latency cost. |

## Top Hypotheses

1. `HYP-BMC-001`: КМ и CSM являются первыми рабочими сегментами DataCanvas.
2. `HYP-BMC-002`: Согласование описания до генерации является ключевой ценностью.
3. `HYP-BMC-003`: Лиса, Оркестратор, A2A и MCP являются обязательными каналами запуска.
4. `HYP-BMC-004`: Экономия времени КМ и снижение ручной работы являются первыми экономическими метриками.
5. `HYP-BMC-005`: Повторный цикл замечаний и исправленной генерации обязателен для принятия результата.

## Следующий Безопасный Шаг

Закрыть запросы evidence из companion/evidence JSON и затем пересобрать BMC artifacts через `npm run generate:bmc`.
