# Business Model Canvas v0.1

Статус: draft

| Блок | Содержание |
|---|---|
| Сегменты пользователей | Команды, которым нужен быстрый проверяемый презентационный артефакт из данных другого агента |
| Ценность | Сокращение времени подготовки краткой презентации без потери трассировки фактов |
| Каналы | Внутренний инструмент, agent workflow, экспорт HTML/PDF/PNG |
| Отношения | Human-in-the-loop review, приемка по evidence |
| Потоки ценности | Экономия времени, снижение ошибок, воспроизводимые презентации |
| Ключевые ресурсы | Входные пакеты, схемы, renderer, evals, trace manifests |
| Ключевые активности | Валидация, нормализация, генерация `PresentationSpec`, рендер, QA/evals |
| Партнеры | Upstream data agent, reviewer, process owner |
| Издержки | LLM cost, latency, review time, maintenance of schemas/evals |

## Правило Использования

Крупный backlog item должен ссылаться на сегмент, ценность, риск или гипотезу из этого BMC.
