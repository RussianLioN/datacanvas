# BMC Source Map

Документ связывает публичные блоки BMC с внутренней трассировкой. Он не является пользовательским BMC-рендером.

| Блок | Раздел | Trace item | Source refs | Clean statement |
|---|---|---|---|---|
| B1 | Сегменты пользователей | BMC-CLM-001 | SRC-DC-VISION-BRANCH-SNAPSHOT, SRC-DC-STORIES-BRANCH-SNAPSHOT | КМ и CSM являются первыми рабочими сегментами DataCanvas; перспективный контур расширяется до пользователей Лисы, которым нужно быстро собрать презентацию из уже подготовленных данных. |
| B2 | Ценностное предложение | BMC-CLM-002 | SRC-DC-BMC-CURRENT, SRC-DC-VISION-BRANCH-SNAPSHOT | DataCanvas сокращает путь от подготовленных данных до рабочей краткой презентации: уточняет недостающее, согласует описание, генерирует файл и поддерживает повторный цикл правок. |
| B3 | Каналы | BMC-CLM-003 | SRC-DC-CO-2026-001, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | DataCanvas запускается двумя основными способами: другим агентом по подготовленному контексту или пользователем в Лисе через диалоговый режим. |
| B4 | Взаимодействие с пользователем | BMC-CLM-004 | SRC-DC-CO-2026-001, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Взаимодействие зависит от режима запуска. |
| B5 | Потоки внутренней пользы | BMC-CLM-005 | SRC-DC-BMC-CURRENT | Для внутреннего продукта блок B5 трактуется как поток пользы: экономия времени, снижение ручной работы, повторное использование шаблонов и измеримый эффект для владельца бюджета. |
| B6 | Ключевые ресурсы | BMC-CLM-006 | SRC-DC-CO-2026-001, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Ключевые ресурсы DataCanvas: подготовленный контекст, правила проверки достаточности и безопасности данных, описание будущей презентации, шаблоны, средство подготовки файла, проверки качества и почтовый канал доставки. |
| B7 | Ключевые активности | BMC-CLM-007 | SRC-DC-CO-2026-001, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | DataCanvas проверяет входные данные, готовит презентацию и отправляет готовый файл пользователю по электронной почте. |
| B8 | Ключевые партнеры | BMC-CLM-008 | SRC-DC-CO-2026-001, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Ключевые партнеры и зависимости: Лиса, другой агент, источники данных, владельцы шаблонов, средство подготовки файла и почтовый канал доставки. |
| B9 | Структура затрат | BMC-CLM-009 | SRC-DC-BMC-CURRENT | Структура затрат включает LLM-вызовы, renderer, human review, задержку, сопровождение, интеграции, шаблоны, эксплуатацию и обработку инцидентов. |
