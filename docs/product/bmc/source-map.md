# BMC Source Map

Документ связывает публичные блоки BMC с внутренней трассировкой. Он не является пользовательским BMC-рендером.

| Блок | Раздел | Trace item | Source refs | Clean statement |
|---|---|---|---|---|
| B1 | Сегменты пользователей | BMC-CLM-001 | SRC-DC-VISION-ACTIVE, SRC-DC-STORIES-CURRENT | Текущий основной пользовательский сегмент DataCanvas — КМ; CSM и другие пользователи Лисы остаются перспективными сегментами развития. |
| B2 | Ценностное предложение | BMC-CLM-002 | SRC-DC-BMC-CURRENT, SRC-DC-VISION-BRANCH-SNAPSHOT | DataCanvas дает пользователю и вызывающему агенту готовый путь от проверенного контекста к рабочей презентации: пользователь получает редактируемый PPTX-файл и нередактируемую PDF-копию, а другой агент может переиспользовать DataCanvas вместо разработки собственного модуля подготовки презентаций. |
| B3 | Каналы | BMC-CLM-003 | SRC-DC-CO-2026-001, SRC-DC-CO-2026-002, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Основные каналы DataCanvas: диалог в Лисе, запуск другим агентом по подготовленному контексту, доставка PPTX- и PDF-файлов по электронной почте и отдельный канал ссылки на PDF-копию с уведомлением в Лисе. |
| B4 | Взаимодействие с пользователем | BMC-CLM-004 | SRC-DC-CO-2026-001, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Взаимодействие с пользователем зависит от режима: в Лисе это управляемый диалог до подготовки презентации, при запуске другим агентом — автоматическое выполнение по подготовленному контексту. |
| B5 | Потоки внутренней пользы | BMC-CLM-005 | SRC-DC-BMC-CURRENT | Для внутреннего продукта DataCanvas поток внутренней пользы выражается в экономии времени, снижении ручной работы, более быстром получении PPTX/PDF-результата и возможности переиспользовать общий презентационный сервис другими агентами. |
| B6 | Ключевые ресурсы | BMC-CLM-006 | SRC-DC-CO-2026-001, SRC-DC-CO-2026-002, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Ключевые ресурсы DataCanvas: подготовленный контекст, данные для определения получателя результата, правила достаточности и безопасности данных, шаблоны презентаций, правила качества, способ подготовки PPTX/PDF-файлов и будущий контур хранения PDF-копии. |
| B7 | Ключевые активности | BMC-CLM-007 | SRC-DC-CO-2026-001, SRC-DC-CO-2026-002, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Ключевые активности DataCanvas: принять задачу и контекст, проверить пригодность входа, определить получателя результата, уточнить недостающее в Лисе при необходимости, подготовить PPTX- и PDF-файлы, отправить результат по электронной почте и в сценарии доставки по ссылке передать вызывающему агенту ссылку для показа пользователю в Лисе. |
| B8 | Ключевые партнеры | BMC-CLM-008 | SRC-DC-CO-2026-001, SRC-DC-CO-2026-002, SRC-DC-REVISION-EDIT-002, SRC-DC-VISION-ACTIVE | Ключевые партнеры DataCanvas: Лиса, другой агент или контур оркестрации, владельцы источников данных, владельцы почтового канала доставки, владельцы защищенного хранилища, команда вызывающего агента и команда Лисы, которые показывают ссылку пользователю. |
| B9 | Структура затрат | BMC-CLM-009 | SRC-DC-BMC-CURRENT | Структура затрат DataCanvas включает вычислительные ресурсы искусственного интеллекта, подготовку редактируемого файла, поддержку интеграций, эксплуатацию и проверки качества. |
