# Руководство Оператора Живого BMC-Интервью

Статус: `draft_runtime_ready`

Документ описывает эксплуатацию живого BMC-интервью DataCanvas.

## Активное Состояние

Текущая сессия хранится в:

- `docs/product/bmc/interviews/active-bmc-interview-runtime-state.json`

Если интервью прервано, продолжать нужно с этого файла.

## Завершенное Состояние

После подтверждения пользователя сохраняются:

- завершенное состояние выполнения;
- расшифровка интервью;
- решения маршрутизации вопросов;
- ответы интервью;
- пользовательские подтверждения;
- итоги интервью;
- обновленную трассировку BMC;
- сгенерированные BMC-артефакты.

## Команды

Проверка состояния выполнения:

```bash
npm run validate:bmc-interview-runtime
```

Проверка воспроизведения сценария:

```bash
npm run validate:bmc-interview-replay
```

Подготовка BMC-артефактов из состояния выполнения:

```bash
npm run prepare:bmc-interview
```

Генерация BMC:

```bash
npm run generate:bmc
```

Полная BMC-проверка:

```bash
npm run validate:bmc
```

## Правила

- Не записывать секреты в расшифровку интервью.
- Не повышать утверждение до `confirmed` без подтверждения.
- Не перезаписывать завершенную сессию без нового `session_id`.
- Если данные неполные, сохранять `draft_unvalidated`.
- Если есть противоречие, не принимать BMC как финальный артефакт.
