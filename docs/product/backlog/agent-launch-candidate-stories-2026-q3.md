## Назначение

Документ показывает срез пользовательских историй по принятым приоритетам для запуска DataCanvas другим агентом и генерации презентации. Он используется как вход для оценки командой и не задает календарный срок реализации. Полный текст историй хранится только в [каноническом каталоге пользовательских историй](../requirements/user-stories.md).
