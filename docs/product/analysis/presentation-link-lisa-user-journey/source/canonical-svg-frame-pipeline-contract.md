# Неактивный договор SVG-first кадров

`CO-2026-003` — заявка на продолжение профиля Лисы в четвертом квартале 2026 года. Этот документ описывает будущий отдельный контур подготовки кадров и не является активным выпуском.

Машиночитаемый договор хранится в [canonical-svg-frame-pipeline-contract.json](canonical-svg-frame-pipeline-contract.json), а его схема — в [schemas/canonical-svg-frame-pipeline-contract.schema.json](schemas/canonical-svg-frame-pipeline-contract.schema.json). Подготовительный кандидат остается версией `1.0.0` в [prototype-revision-candidate.json](prototype-revision-candidate.json); текущий документ имеет версию `3.1.0`, потому что исправляет состав будущих визуальных доноров и не меняет кандидата v1.

Договор не включен в [active-contracts.json](active-contracts.json), не является входом генератора и не разрешает рендер, архив или переключение активного выпуска. Он только фиксирует будущие требования: 11 кадров берутся из `active_future_frame_ids` кандидата v1, два исторических кадра остаются ссылками, а галерея для заинтересованных лиц не становится переходом сценария.

Владелец уже выбрал все пять текстов: подпись кнопки, сообщение о начале формирования, сообщение об успешной отправке, тему и тело письма. Единственный источник этих формулировок — [реестр выбранных текстов](../owner-approved-texts.md). Три PDF вариантов презентации получены и зарегистрированы как визуальные доноры в [реестре PDF-доноров](presentation-pdf-donor-register.json), но не являются прямым входом рендера. До любой отрисовки для каждого из них нужен канонический SVG. Отдельно всё ещё нужен канонический SVG кадра письма.

Очищенные данные [справки по клиенту](client-reference-data.json) обязательны для замены исторического маркера «ГК Достовалова» в существующих группах SVG полной справки и её продолжений. Данные не накладываются поверх изображения: сначала заменяется содержимое существующей группы SVG с сохранением оформления, затем проводится поэкранная приёмка.

PNG выпуска всегда должны получаться из утвержденных SVG-источников. Это нужно, чтобы финальный высокий рендер не зависел от ручных наложений текста, HTML, CSS или увеличения чернового PNG. Сам SVG при этом не становится исполняемым браузерным ресурсом: он остается каноническим исходником для проверки групп, текста и последующей растеризации, а не частью активной страницы.

Каждый из 11 будущих кадров согласуется отдельно. В проверочной изолированной копии текущего прототипа разрешено заменить только один одноимённый кадр; до явной приёмки владельца нельзя переходить к следующему. Действующий выпуск при этом не меняется.

Откат работает только полным комплектом. Будущее переключение должно транзакционно обновлять активный реестр, договор сценария, кадровый или визуальный договор, каталог источников и рендера, `demo/**`, `derived/**`, `evidence/**`, переносимый ZIP и архив поставки. Если финальное подтверждение не получено или выпуск не проходит проверку, активный комплект возвращается целиком, без частичной публикации кадров или доказательств.
