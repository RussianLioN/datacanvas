# Договор контролируемого импорта PDF-презентаций

Для трёх самостоятельных презентационных кадров используются готовые PDF ООО «Водолей Трейд». Это не мобильные экраны Лисы: SVG-first правило для них не применяется.

Единственный допустимый путь: утверждённый PDF во временном локальном каталоге → штатный импортёр Swift/CoreGraphics → канонический PNG → изолированная покадровая приёмка → PNG `4×` для выпуска. PDF не хранится в Git, не включается в архив и не открывается браузерной демонстрацией.

Каждый вариант состоит из трёх страниц и согласуется как один прокручиваемый презентационный кадр. Владелец дал предварительное разрешение сразу подготовить черновики SlideDoc, Sber 2025 и MAG, чтобы увидеть их вместе с остальными кадрами в изолированной копии прежнего прототипа. Эта копия обязана сохранять без изменений её оформление и навигацию: служебную панель, счётчик, стрелки, прокрутку телефона и страниц презентации. В ней заменяются `data.js`, изображения кадров и единственный строго контролируемый фрагмент `app.js`, который открывает пять заданных мобильных кадров в нижней части обычного чата. Этот фрагмент не добавляет новых элементов и не ограничивает прокрутку; отдельный упрощённый просмотрщик запрещён. Это разрешение не является приёмкой ни одного из трёх кадров: перед высоким разрешением для каждого из них всё ещё нужна отдельная явная приёмка. Высокое разрешение не готовится заранее: его преобразование будет добавлено только после принятия всех трёх черновиков.

Размер чернового PNG не задаёт размер показа. Каждая страница всегда показывается в историческом окне `960×540`, а три страницы прокручиваются внутри той же сцены, что и в прежнем прототипе. Черновой источник сохраняется в однократном разрешении, но его экранная геометрия калибруется по историческому четырёхкратному растру; это не является высоким рендером и не заменяет его. Высокий PNG `4×` создаётся заново только из исходного PDF после индивидуальной приёмки всех трёх вариантов.

Машиночитаемый источник истины — [presentation-pdf-raster-import-contract.json](presentation-pdf-raster-import-contract.json); его схема — [presentation-pdf-raster-import-contract.schema.json](schemas/presentation-pdf-raster-import-contract.schema.json).
