# Технический паспорт прототипа Лисы из десяти состояний

Навигация: [DataCanvas](../../../../README.md) / [Документация](../../../README.md) / [Продукт](../../README.md) / [Аналитика](../README.md) / [Путь заказа презентации](README.md) / Технический паспорт

## Назначение

Паспорт описывает договорный слой автономного прототипа. Продуктовый порядок экранов находится в [пользовательском пути](user-journey.md); машинные ограничения закреплены в JSON-договорах каталога `source/`.

## Активные договоры

[Реестр активных договоров](source/active-contracts.json) является единственным входом генератора. Он ссылается только на пять рабочих договоров: путь, кадры, каталог исходных рендеров, визуальную основу и минимальный пакет. Дополнительные старые договоры на диске не входят в активный набор, если они не перечислены в этом реестре.

## Растровая основа и кнопки

[Договор визуальной основы](source/visual-basis-contract.json) связывает каждое телефонное состояние с тремя очищенными растровыми основами тройной плотности и их ресурсами в `demo/assets/`: `system_top` — системная строка, `scroll_content` — содержимое приложения, `system_bottom` — домашний индикатор. Кнопка заказа задана только для `lisa-materials-summary`, `lisa-materials-full-reference` и `lisa-presentation-order`; все три области находятся в `scroll_content` и ведут к `lisa-presentation-generating`.

Полный исходный холст имеет ширину 521, но его поля не определяют границы мока. Внешний прямоугольник сохраняет физические пропорции корпуса 78,1×160,8 мм; защищённая область исходника `x=64, y=48, width=393, height=852` центрируется внутри него без растяжения и обрезается по исходному радиусу 32 точки. Внешняя оболочка остаётся прозрачной, поэтому разница по ширине и области за скруглениями показывают единый нейтральный фон визуального фрейма без второго контура. Телефон центрируется в области справа от служебной панели. Неподвижные системные области занимают 53 точки сверху и 34 точки снизу. Среднее окно высотой 765 точек прокручивает содержимое высотой 4979 для `5.4`; остальные пять телефонных состояний не имеют запаса прокрутки. Письмо является самостоятельным десктопным кадром 1553×1013 и полностью заполняет собственную сцену того же соотношения сторон. Три варианта презентации используют окно 960×540 и внутренний вертикальный растр 960×1620 условных точек; PNG 3840×6480 обеспечивает четырёхкратную плотность. CSS меняет только размер сцены под доступное окно, сохраняя 16:9 и не увеличивая растр выше его физической плотности.

## Минимальный архив

[Договор пакета](source/prototype-package-contract.json) задаёт `runtime_root` как `demo`, `asset_root` как `demo/assets` и минимальный список из 28 членов архива: шесть служебных файлов, 18 телефонных PNG-сегментов, один PNG почты и три PNG вариантов презентации. Внутри ZIP файлы демонстрации лежат в корне, а изображения — в `assets/` без промежуточного каталога `bases`. Сырые SVG, исходные PDF, полные телефонные PNG старой модели, родительские переходы `..`, абсолютные локальные пути, сетевые запросы и зависимость времени исполнения от `source/**` запрещены.

## Проверка

Сборка выполняется командой `npm run generate:presentation-link-lisa-user-journey`. Проверка договоров, свежести растров, автономного архива и поведения страницы выполняется командами `npm run validate:presentation-link-lisa-user-journey` и `npm run test:presentation-link-lisa-user-journey:browser`.
