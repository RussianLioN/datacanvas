# Черновой кадр: данные не приняты

Статус: ожидает отдельной приёмки владельца. Это изолированный PNG в прежнем разрешении; действующая демонстрация, высокий рендер и архив не меняются.

Кадр продолжает принятую полную справку по ООО «Водолей Трейд»: кнопка остаётся погашенной, а сообщение о начале формирования заменено сообщением о непринятии данных. Системное время телефона — `13:40`.

## Текст сообщения

> Не удалось принять данные для формирования презентации. Вернитесь к диалогу «Справка по клиенту» и уточните данные, либо оформите тикет в сопровождение.

- [Черновой PNG](draft-current-resolution.png) — кадр для просмотра.
