# Черновой кадр: начало формирования презентации

Статус: ожидается отдельная приёмка владельца. Это изолированный черновой кадр
в прежнем разрешении, а не изменение действующей демонстрации или архива.

## Что продолжено

- Основание — штатный SVG `7.2 — Длинное название клиента + холдинг.svg` для
  состояния начала формирования презентации.
- В карточке справки показаны данные ООО «Водолей Трейд»: наименование, ИНН,
  Сибирский банк, сегмент «Средний», ГК «Водолей» и численность 90 человек.
- В верхней контурной кнопке и в сообщении пользователя сохранён выбранный
  текст «Создать презентацию по справке».
- Сообщение агента содержит утверждённый текст: «Формирование презентации
  началось в ЧЧ:ММ и займет не более 20 минут. После завершения презентация
  будет направлена по электронной почте в SIGMA и OMEGA.» В черновике время
  показано как `13:24` — в формате ЧЧ:ММ.

## Материалы для проверки

- [SVG-источник](source.svg) — единственный источник нового текста и его
  расположения.
- [Черновой PNG в прежнем разрешении](draft-current-resolution.png) —
  растеризация этого SVG, размер 521×980 пикселей.
- [Манифест проверки](review-source-manifest.json) — отпечатки источников,
  перечень заменённых существующих групп и запрет изменения действующего
  выпуска.

## Обязательные проверки

1. Новые тексты заменяют содержимое существующих SVG-групп карточки, сообщения
   пользователя и статуса; в SVG нет HTML, CSS, PNG-наложений, новых белых
   карточек, плавающих облаков или самостоятельных текстовых элементов.
2. В карточке и обоих вариантах действия указан один клиент: ООО «Водолей
   Трейд». Старое наименование «ГК Достовалова» не выводится.
3. Сообщение о начале содержит время `13:24`, обещание «не более 20 минут»,
   электронную почту и оба контура SIGMA и OMEGA; нет грубого побудительного
   предложения.
4. PNG получен заново из этого SVG, а не наложением на прежнее изображение.

До отдельной приёмки этого кадра нельзя менять следующий кадр, собирать новый
прототип, высокое разрешение, доказательства или архив поставки.
