# Черновой кадр: начало формирования презентации

Статус: принят владельцем 24 августа 2026 года. Это изолированный черновой кадр
в прежнем разрешении, а не изменение действующей демонстрации или архива.

## Что показано

- Основание — [принятый SVG полной справки](../lisa-materials-full-reference/source.svg) по ООО «Водолей Трейд». Его отпечаток и решение «кадр принят» сверяются по [записи приёмки](../lisa-materials-full-reference/owner-approval.json).
- Все видимые разделы полной справки сохранены без сокращения и перестановки. Короткий экран `7.2` не используется.
- Внутри существующей группы нижней кнопки сохранены её форма, размер и надпись «Создать презентацию по справке». После нажатия она поднимается внутри расширенной фиксированной нижней панели, получает бледно‑серый фон и неактивное состояние.
- Непосредственно под погашенной кнопкой добавлено сообщение: «Формирование презентации началось в ЧЧ:ММ и займет не более 20 минут. После завершения презентация будет направлена по электронной почте в SIGMA и OMEGA.» В черновике время показано как `13:24` — в формате ЧЧ:ММ. Его шрифт, кегль и цвет совпадают с обычным текстом полной справки.
- В будущем прототипе это будет динамическая смена состояния того же полного экрана. Сейчас подготовлен только изолированный кандидат для покадровой приёмки.

## Материалы для проверки

- [SVG-источник](source.svg) — единственный источник нового текста, состояния кнопки и их расположения.
- [Черновой PNG в прежнем разрешении](draft-current-resolution.png) — растеризация этого SVG, размер 521×3226 пикселей: высота увеличена только для расширенной нижней панели.
- [Манифест проверки](review-source-manifest.json) — привязка к принятому первому SVG, перечень изменённых существующих групп и запрет изменения действующего выпуска.

## Обязательные проверки

1. Новый текст подготовлен в самом SVG векторными контурами: внутри существующей группы нижней панели, после её штатной подложки, и без HTML, CSS или PNG-наложений. В нём нет новой белой карточки, плавающего облака или самостоятельного текстового элемента.
2. Все видимые разделы продолжают принятую справку по ООО «Водолей Трейд»; старое наименование «ГК Достовалова» не выводится.
3. Сообщение о начале содержит время `13:24`, обещание «не более 20 минут», электронную почту и оба контура SIGMA и OMEGA; нет грубого побудительного предложения.
4. PNG получен заново из этого SVG, а не наложением на прежнее изображение.

Решение «кадр принят» и отпечатки SVG и PNG сохранены в
[записи приёмки](owner-approval.json). Следующим допускается только изолированный
черновой кадр успешной отправки; новый прототип, высокое разрешение, доказательства
и архив поставки всё ещё запрещены.
