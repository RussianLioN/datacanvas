# Результат брейншторма по тексту кнопки

Навигация: [DataCanvas](../../../../../../README.md) / [Документация](../../../../../README.md) / [Продукт](../../../../README.md) / [Аналитика](../../../README.md) / [Пользовательский путь заказа презентации в Лисе](../../README.md) / Неактивный результат брейншторма

`CO-2026-003` — изменение Q4_2026 для заказа презентации из агента «Справка по клиенту» в Лисе.

Статус: `pending_owner_selection`.

Этот пакет является неактивным свидетельством по теме `button_label` — текст кнопки заказа презентации. Он не меняет действующие договоры, не разрешает рендер, не входит в архив и не является входом генератора.

## Вводная владельца

Кнопка должна ясно связывать «Справку по клиенту» и презентацию. Текст должен быть максимально коротким; предпочтительно не более трёх слов. Пример «сформировать презентацию по справке» не является вариантом для использования.

## Первая фаза

Участников: 19. Минимум вариантов на участника: 20. Всего сырых вариантов: 380. Контекст был общий и видимый участникам первой фазы.

Полный журнал сырых вариантов сохранён в [raw-variants-ledger.md](raw-variants-ledger.md).

### Контроль качества

Перед консолидацией выполнена автоматическая проверка точного совпадения всех 380 вариантов: повторов не осталось. Если вариант требует замены, номер участника сначала сверяется с записью, которой принадлежит повтор.
