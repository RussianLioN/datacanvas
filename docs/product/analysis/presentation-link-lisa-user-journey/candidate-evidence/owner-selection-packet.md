# Исторический пакет кандидатов будущего прототипа

Статус: обсуждение завершено. Этот документ сохраняет по пять кандидатов из двухфазного обсуждения. Он не является первичным протоколом отметок команды и не заменяет редакционные правки владельца. Единственный источник истины для дальнейших правок — [утверждённые тексты](../owner-approved-texts.md).

## Итог выбора владельца продукта

- **Текст кнопки заказа презентации:** «Создать презентацию по справке» — выбран лидер опроса команды.
- **Сообщение о начале формирования презентации:** «Формирование презентации началось в ЧЧ:ММ и займет не более 20 минут. После завершения презентация будет направлена по электронной почте в SIGMA и OMEGA.» — выбран лидер опроса команды.
- **Сообщение об успешной отправке презентации:** «Презентация готова и направлена по электронной почте в ЧЧ:ММ.» — утверждена редакционная правка владельца после опроса команды.
- **Тема письма с презентацией:** «Презентация по справке ООО «Водолей Трейд»» — владелец разрешил ничью между лидерами опроса.
- **Тело письма с презентацией:** «Во вложении презентация по Справке по клиенту ООО «Водолей Трейд».» — утверждена редакционная правка владельца после опроса команды.

Во внешнем пакете владельца были отмечены результаты опроса команды и, где требовалось, внесены редакционные правки. В репозитории сохраняются только проверяемые итоги выбора: число отметок, способ выбора и финальный текст; имя файла, путь и метаданные внешнего пакета не сохраняются.

До покадровой SVG-приёмки, получения редактируемых исходников и отдельного согласования каждого чернового PNG запрещено менять визуальные кадры и выпускать прототип.

## Сообщение о начале формирования презентации

Источник: [полный результат двухфазного обсуждения](generation-started-message/brainstorming-topic-result.md); применено редакционное уточнение владельца без нового брейншторма.

1. Формирование презентации началось в ЧЧ:ММ. Срок — не более 20 минут; затем презентация будет направлена по электронной почте в SIGMA и OMEGA.
2. Формирование презентации началось в ЧЧ:ММ и займет не более 20 минут. После завершения презентация будет направлена по электронной почте в SIGMA и OMEGA.
3. В ЧЧ:ММ начато формирование презентации. Срок выполнения — не более 20 минут; по завершении презентация будет направлена по электронной почте в SIGMA и OMEGA.
4. Формирование презентации начато в ЧЧ:ММ. Срок подготовки — не более 20 минут, затем презентация будет направлена по электронной почте в SIGMA и OMEGA.
5. В ЧЧ:ММ началось формирование презентации. Оно займет не более 20 минут, после чего презентация будет направлена по электронной почте в SIGMA и OMEGA.
