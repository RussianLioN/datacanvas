# Утверждённые тексты будущего прототипа

Навигация: [DataCanvas](../../../../README.md) / [Документация](../../../README.md) / [Продукт](../../README.md) / [Аналитика](../README.md) / [Пользовательский путь заказа презентации в Лисе](README.md) / Утверждённые тексты

`CO-2026-003` — заявка на изменение Q4_2026 для заказа презентации из агента «Справка по клиенту» в Лисе.

Статус: утверждено владельцем продукта 20 августа 2026 года. Этот документ — человекочитаемая обёртка единого машиночитаемого источника [source/owner-approved-texts.json](source/owner-approved-texts.json).

## Утверждённые формулировки

1. **Текст кнопки заказа презентации:** «Создать презентацию по справке».
2. **Сообщение о начале формирования:** «Формирование презентации началось в ЧЧ:ММ и займет не более 20 минут. После завершения презентация будет направлена по электронной почте в SIGMA и OMEGA.»
3. **Сообщение об успешной отправке:** «Презентация готова и направлена по электронной почте в ЧЧ:ММ.»
4. **Тема письма:** «Презентация по справке ООО «Водолей Трейд»».
5. **Тело письма:** «Во вложении презентация по Справке по клиенту ООО «Водолей Трейд».»

## Как получен результат

По каждой из пяти тем сначала сохранён результат двухфазного брейншторма: первая группа подготовила варианты, вторая независимо отобрала кандидаты. Эти материалы остаются историческими и не переписываются:

- [кнопка](candidate-evidence/button-label/brainstorming-topic-result.md);
- [начало формирования](candidate-evidence/generation-started-message/brainstorming-topic-result.md);
- [успешная отправка](candidate-evidence/delivery-success-message/brainstorming-topic-result.md);
- [тема письма](candidate-evidence/email-subject/brainstorming-topic-result.md);
- [тело письма](candidate-evidence/email-body/brainstorming-topic-result.md).

Команда отметила варианты знаком `+` в переданном владельцем пакете. Подпись кнопки и сообщение о начале формирования дословно совпали с лидерами исторических кандидатов. Для сообщения об успехе и тела письма владелец утвердил редакционные правки после опроса. В теме письма два лидера получили по четыре отметки; владелец продукта выбрал первый из них: «Презентация по справке ООО «Водолей Трейд»». Затем владелец продукта подтвердил все пять формулировок в рабочем диалоге.

Исторические кандидаты дают контекст, но не подменяют этот реестр и не используются как буквальный протокол отметок. В репозитории сохранены только число отметок, способ выбора и итоговый текст; внешний пакет, его имя, путь и метаданные не сохраняются.

## Граница следующего этапа

Утверждение текстов не разрешает рендер. Новые кадры можно готовить только по договору: правка существующей группы канонического SVG, визуальная проверка SVG, черновой PNG кадра, явная приёмка кадра, затем черновик всего прототипа и лишь после этого высокий рендер из согласованных SVG. До получения редактируемых исходников и покадровой приёмки запрещены новые PNG, HTML и архив.
