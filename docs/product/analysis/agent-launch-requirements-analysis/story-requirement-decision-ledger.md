| Решение | История | Затронутые `BT-*` — бизнес-требования | Итог | Обоснование |
|---|---|---|---|---|
| `ALRA-DEC-001` — решение по передаче запроса | `DC-ST-23` — пользовательская история о передаче запроса на подготовку презентации от другого агента | `BT-001` — структурированный вход; `BT-005` — запуск подготовки; `BT-012` — подготовка и доставка; `BT-014` — трассировка | Оставить существующие требования без изменения | Текущие формулировки уже описывают прием задания от другого агента, проверяемый вход, подготовку результата и связь доказательств. |
| `ALRA-DEC-002` — решение по общему агентскому сценарию | `DC-ST-24` — пользовательская история о запуске DataCanvas в общем сценарии с другими агентами | `BT-005` — запуск подготовки; `BT-014` — трассировка | Оставить существующие требования без изменения | История уточняет бизнесовый контекст `DC-ST-23` — передачи запроса — и не добавляет отдельную бизнесовую потребность с новыми границами. |
| `ALRA-DEC-003` — решение по входному пакету | `DC-ST-25` — пользовательская история о входном пакете с задачей, источником запроса и параметрами презентации | `BT-001` — структурированный вход; `BT-006` — проверка недоверенного входа | Оставить существующие требования без изменения | Бизнесовый состав входа покрыт, а технический контракт входного пакета не утверждается этим анализом. |
| `ALRA-DEC-004` — решение по проверке входа | `DC-ST-26` — пользовательская история о проверке входного пакета | `BT-006` — проверка недоверенного входа; `BT-013` — защита prompt, trace, evidence, runtime state, email и export | Оставить существующие требования без изменения | Недостаточный или небезопасный вход уже останавливает обработку до генерации и отправки. |
| `ALRA-DEC-005` — решение по статусам и обратному вызову | `DC-ST-27` — пользовательская история о статусах обработки и сведениях о результате через обратный вызов | `BT-012` — подготовка и доставка; `BT-014` — трассировка | Оставить существующие требования без изменения | Статусы и сведения о результате покрыты как проверяемые данные жизненного цикла; реальная callback-интеграция не включается. |
| `ALRA-DEC-006` — решение по проверяемости запуска | `DC-ST-28` — пользовательская история о trace ID, источнике запроса, результате проверки, статусах и связях с итоговыми артефактами | `BT-014` — трассировка жизненного цикла | Оставить существующие требования без изменения | `BT-014` — бизнес-требование о трассировке — уже покрывает проверяемость запуска другим агентом и связь с итоговыми артефактами. |

Новые идентификаторы `BT-*` — бизнес-требований — не назначались.
