## Блокирующий Вывод

Нельзя сразу сформировать окончательный sprint backlog — список работ спринта — без проверки ПШЕ командой реализации, проверки емкости, решения по вытеснению работ и последующей ревизии зависимых артефактов. Безопасный следующий шаг: проверить значения по матрице `agent-launch-p1-effort-estimation.md`, затем вернуться к sprint backlog и roadmap — дорожной карте.
