## Блокирующий Вывод

Нельзя сразу сформировать окончательный sprint backlog — список работ спринта — без проверки емкости, порядка работ, решения по вытеснению работ и последующей ревизии зависимых артефактов. Безопасный следующий шаг: использовать принятую матрицу `agent-launch-p1-effort-estimation.md` как ресурсный вход, затем вернуться к sprint backlog и roadmap — дорожной карте.
