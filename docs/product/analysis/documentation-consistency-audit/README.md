## Назначение

Пакет фиксирует рабочий проход `UDW-RUN-2026-07-05-003` — аудит согласованности проектной документации DataCanvas после принятия `CO-2026-001` — заявки на приоритет запуска DataCanvas другим агентом.

Цель прохода — проверить, что Vision — видение продукта, BMC — Business Model Canvas, бизнес-модель продукта, пользовательские истории, бизнес-требования, критерии приемки, backlog — продуктовый список работ, roadmap — дорожная карта, traceability — трассировка, BA/SA artifacts — артефакты бизнес- и системного анализа, specs — спецификации, generated artifacts — автоматически создаваемые артефакты — и Confluence-маршрут не противоречат друг другу.

## Границы

- Аудит не меняет продуктовый смысл DataCanvas без решения Product Owner — владельца продукта.
- Аудит не меняет процессные правила без Process Owner — владельца процесса.
- Аудит не выводит бизнесовый смысл из `ADR-*` — архитектурных решений, schemas — схем или scripts — скриптов.
- Generated artifacts — автоматически создаваемые артефакты — обновляются только генераторами.
- Итоговый Confluence-результат на этом шаге — карта импорта Markdown/PDF/PNG, а не фактическая загрузка в корпоративный Confluence.
