# Диаграммы последовательности пользовательских историй 2026

Навигация: [DataCanvas](../../../../README.md) / [Документация](../../../README.md) / [Продукт](../../README.md) / [Требования](../README.md) / Диаграммы последовательности

## Назначение

Этот принятый набор показывает взаимодействие участников в 24 детализированных
сценариях девяти пользовательских историй DataCanvas 2026 года. Он помогает
продуктовому и системному анализу сверять порядок действий, статусы и границы
ответственности без изменения утверждённого текста историй.

Канонический текст сценариев находится в [каталоге пользовательских историй](../user-stories.md).
Для каждого сценария доступны исходник PlantUML, SVG и PNG. [Манифест набора](../../../../artifacts/evidence/co-2026-003/user-story-sequence-diagrams/manifest.json)
фиксирует целостность производных файлов; он не заменяет этот обзор для чтения.
