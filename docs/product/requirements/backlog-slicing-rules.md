# Backlog Slicing Rules

- Один item должен давать проверяемый недельный результат.
- Discovery и delivery не смешиваются без явного spike.
- Если item требует новую схему, eval или security rule, это указывается в DoR.
- Item не попадает в Sprint Backlog без acceptance criteria и способа проверки.
- Large item режется по risk, user signal, reusable capability или dependency.
