## Базовый MVP gate

- Входной пакет валидируется по схеме и проходит data classification.
- Нормализованные данные сохраняют ссылки на источники.
- Недостаточный вход останавливает подготовку презентации; уточняющие вопросы задаются в Лисе, если сценарий идет в диалоговом режиме.
- При запуске другим агентом DataCanvas после проверки достаточности и безопасности данных готовит презентацию без пользовательского подтверждения и отправляет файл по электронной почте.
- В диалоговом режиме в Лисе DataCanvas показывает описание структуры, после чего пользователь выбирает: изготовить презентацию или перейти к редактированию структуры.
- `PresentationSpec` проходит schema validation.
- Renderer создает проверяемый HTML/PDF/PNG export в текущем техническом baseline.
- Каждый финальный claim связан с источником.
- Export, email metadata и evidence не содержат raw traces, hidden notes, local paths, secrets, PII, internal prompts или tool outputs.
- Sprint evidence содержит input, output, checks, limitations и решение приемки.

## Сценарии приемки P1-P2

| Сценарий | Связанные BT | Ожидаемый результат | Ожидаемое доказательство |
|---|---|---|---|
| Запуск другим агентом | `BT-005`, `BT-006`, `BT-012`, `BT-014` | DataCanvas получает подготовленный контекст, проверяет достаточность и безопасность данных, готовит презентацию без пользовательского подтверждения и отправляет файл по электронной почте | Доказательства связывают request, input, результат проверки, готовый файл и статус доставки |
| Диалоговый режим в Лисе | `BT-005`, `BT-007`, `BT-008`, `BT-009`, `BT-010`, `BT-012`, `BT-014` | Пользователь видит описание структуры и выбирает: изготовить презентацию или перейти к редактированию структуры; после выбора изготовления файл отправляется по электронной почте | Доказательства связывают request, input, описание структуры, выбор пользователя, возможные правки, готовый файл и статус доставки |
| Недостаточный входной контекст | `BT-006`, `BT-007` | Недостаточные данные не приводят к изготовлению презентации; в Лисе DataCanvas задает уточняющие вопросы | Доказательства содержат missing fields, набор вопросов при наличии и отсутствие готового файла |
| Правка до генерации | `BT-010` | Пользователь в Лисе дополняет, перемещает или удаляет блоки до генерации | Change log description фиксирует действия до изготовления презентации |
| Выбор формата и шаблона | `BT-011` | КМ выбирает формат и шаблон из предложенных вариантов | Evidence фиксирует выбранные format/template и открытое решение по каталогу |
| Доставка по электронной почте | `BT-012`, `BT-014` | Готовый файл отправлен по электронной почте, статус доставки зафиксирован | Статус доставки связан с request/export IDs; содержимое письма не раскрывает лишние данные |
| Неподтвержденный claim | `BT-003`, `BT-013` | Неподтвержденный claim уточняется или исключается | Claim map показывает отсутствие unsupported claim в финальном результате |
| Конфликтующие источники | `BT-003`, `BT-014` | Конфликтующие данные не становятся финальным claim без разрешения | Trace содержит конфликт и решение: уточнение, исключение или выбранный источник |
| Prompt injection | `BT-006`, `BT-013` | Инструкции из входного текста, agent output или вложений не меняют правила DataCanvas | Правило остановки или sanitization evidence фиксирует обработку как данных |
| Утечка secrets/PII | `BT-004`, `BT-013` | Секреты и PII не попадают в prompt, trace, evidence, email или export | Secret scan и data leakage checks проходят; evidence redacted |
| Guard против P3-P5 | `BT-005` - `BT-014` | В MVP `P1-P2` не появляются будущие возможности | Требования и traceability покрывают только `DC-ST-01..DC-ST-09` |

## Открытые решения для приемки

- `PPTX/PDF` рассматриваются как продуктовое решение для проверки, но не как утвержденный технический контракт renderer.
- Рабочая почта пользователя рассматривается как продуктовое решение для проверки, но правила адресата и подтверждения доставки остаются открытыми.
- `DC-ST-03/04` проходят приемку по действию с описанием презентации; бизнес-ценность не дописывается без отдельного источника.
