# Нефункциональные Требования v0.1

Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Продукт](../README.md) / [Требования](README.md) / Нефункциональные требования

| ID | Категория | Требование | Метрика |
|---|---|---|---|
| NFR-001 | Достоверность | Неподтвержденное утверждение не попадает в финальную презентацию. | 0 неподтвержденных утверждений в результате. |
| NFR-002 | Воспроизводимость | Для результата можно восстановить вход, версию правил обработки, редактируемый файл, нередактируемую копию и статус доставки. | Полная проверяемая связь результата с входом, правилами обработки и доставкой. |
| NFR-003 | Конфиденциальность | Секреты, персональные данные и служебные следы не попадают в готовые файлы, почтовую доставку, публичные материалы или будущую ссылку на результат. | 0 выявленных утечек. |
| NFR-004 | Производительность | Стоимость и задержка подготовки результата контролируются для каждого запуска. | Стоимость и задержка остаются в согласованных границах. |
| NFR-005 | Визуальное качество | Готовый файл не содержит критичных дефектов верстки. | 0 критичных визуальных дефектов. |

## Критерии Пригодности Для BA/SA

| ID | Категория | Критерий | Условие приемки |
|---|---|---|---|
| NFR-001 | Достоверность | Утверждение из интервью не становится требованием или критерием приемки без подтверждения источником. | Неподтвержденное утверждение помечено как гипотеза, уточнено или исключено. |
| NFR-002 | Воспроизводимость | Ответы интервью связаны с требованиями, критериями приемки и проверяемыми артефактами. | Для каждого принятого требования понятен источник и ожидаемый способ проверки. |
| NFR-003 | Конфиденциальность | Рабочие материалы для анализа не содержат лишний сырой пользовательский контекст. | В артефактах остается только необходимый и разрешенный контекст. |
| NFR-004 | Наблюдаемость | Рабочий проход можно восстановить по его идентификатору, входам, результатам и итоговому статусу. | Ход прохода понятен без локальных путей, секретов и сырых служебных следов. |
| NFR-005 | Совместимость | Границы взаимодействия описаны так, чтобы их можно было связать с требованиями и архитектурными контрактами. | Для каждой границы есть понятное назначение, владелец и условие проверки. |

## Связь С Рисками

- `NFR-001` связан с риском неподтвержденных утверждений.
- `NFR-003` связан с риском раскрытия секретов, персональных данных или служебных следов.
- `NFR-004` связан с рисками превышения задержки, стоимости и ненадежности поставщика.
