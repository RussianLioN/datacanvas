# Нефункциональные требования v0.1

Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Продукт](../README.md) / [Требования](README.md) / Нефункциональные требования

## Назначение

Документ фиксирует требования к качеству результата и границам работы DataCanvas. Проверочные механизмы и служебные журналы ведутся во внешнем проверочном контуре.

## Нефункциональные требования

| ID | Категория | Требование | Условие приемки |
|---|---|---|---|
| NFR-001 | Достоверность | Неподтвержденное утверждение не попадает в финальную презентацию. | В результате нет неподтвержденных утверждений. |
| NFR-002 | Воспроизводимость | Для результата можно восстановить вход, версию правил обработки, редактируемый `PPTX`-файл, нередактируемую `PDF`-копию и статус доставки. | Для каждого результата понятна связь с входом, правилами обработки и доставкой. |
| NFR-003 | Конфиденциальность | Секреты, персональные данные и служебные следы не попадают в `PPTX`-файл, `PDF`-копию, почтовую доставку, публичные материалы или будущую ссылку на результат. | Результат и доставка не раскрывают лишние данные. |
| NFR-004 | Производительность | Стоимость и задержка подготовки результата контролируются для каждого запуска. | Стоимость и задержка остаются в согласованных границах. |
| NFR-005 | Визуальное качество | Готовый файл не содержит критичных дефектов верстки. | Пользователь может использовать результат как рабочий презентационный материал. |
| NFR-006 | Совместимость | Границы взаимодействия DataCanvas с другим агентом, Лисой, электронной почтой и защищенным хранилищем описаны так, чтобы команда могла связать их с требованиями и архитектурными контрактами. | Для каждой границы понятны назначение, владелец и условие приемки. |

## Открытые вопросы

| Область | Что нужно уточнить |
|---|---|
| Производительность | Согласованные пределы стоимости и задержки подготовки результата. |
| Визуальное качество | Минимальные критерии приемлемого оформления для пилотного результата. |
| Защищенное хранилище | Требования к доступу по ссылке и сроку жизни нередактируемой копии. |
