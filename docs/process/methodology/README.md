## Назначение

Этот раздел фиксирует методическую основу для ведения проектной документации DataCanvas. Основа получена из пользовательской инструкции по применению BABOK-исследования и из исследовательского отчета о сквозной цепочке ИТ-продукта.

Методика используется как источник правил для:

- определения жизненного цикла проектной документации;
- классификации обязательных и условных артефактов;
- связи бизнес-анализа, системного анализа, backlog, acceptance, тестов, release evidence и эксплуатации;
- проверки готовности документации перед продолжением интервью, refinement или переоприоритезации.

## Правило Использования

Методика не заменяет бизнесовые источники продукта. Vision, BMC, stories, требования, product backlog, roadmap, hypotheses и traceability остаются источниками продуктового смысла.

Методика отвечает на другой вопрос: какие артефакты должны существовать, в какой последовательности они уточняются, какие связи обязательны и какие gates подтверждают готовность.
