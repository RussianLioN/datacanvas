# Sprint Folder Template

Создавайте отдельную папку `docs/sprints/YYYY-WW-name/`.

Обязательные файлы:

- `sprint-goal.md`;
- `sprint-backlog.md`;
- `planning.md`;
- `daily-notes.md`;
- `review.md`;
- `retro.md`;
- `decisions.md`;
- `evidence-index.md`;
- `artifact-updates.md`;
- `process-change-candidates.md`;
- `sprint-summary.md`;
- `sprint-evidence-manifest.json`.

Правило: sprint evidence не должен содержать фиктивные результаты внешней приемки.
