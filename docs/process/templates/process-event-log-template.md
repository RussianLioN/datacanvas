# Process Event Log Template

## Event Types

Минимальные типы событий:

- sprint planned;
- sprint reviewed;
- backlog item started;
- backlog item accepted;
- blocked;
- unblocked;
- process change proposed;
- process change decided;
- decision requested;
- decision accepted.

## Правило

Live delivery metrics остаются `n/a`, пока в журнале нет событий, покрывающих расчет метрики.
