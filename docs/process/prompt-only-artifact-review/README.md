# Prompt-Only Согласование Артефактов Проектной Документации

Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Процесс](../README.md) / Prompt-only согласование артефактов

Статус: active
Владелец: Process Owner
Проверка: `npm run validate:prompt-only-artifact-review`

## Назначение

Пакет задает рабочий процесс согласования и редактирования артефактов проектной документации одним текстовым запросом. Он обслуживает документационный контур DataCanvas и не задает поведение продукта DataCanvas.

Пользователь запускает процесс обычным сообщением в чате. Агент сам читает состояние, каталог ссылок, журнал решений и runbook — инструкцию выполнения, затем показывает артефакты, собирает решения, обновляет согласованные источники, запускает генераторы и проверки.

## Запуск

Минимальный текстовый запрос:

```text
Запусти prompt-only процесс согласования и редактирования артефактов проектной документации DataCanvas по docs/process/prompt-only-artifact-review/README.md.
```

Агент не должен просить пользователя вручную запускать `npm` команды. Команды генерации и проверки выполняет агент, а пользователь отвечает только на вопросы согласования.

## Состав

- [Runbook](prompt-only-runbook.md) — инструкция для агента по запуску, продолжению и завершению процесса.
- [Artifact link catalog](artifact-link-catalog.json) — каталог исходных, производных, evidence и навигационных артефактов.
- [Artifact review session state](artifact-review-session-state.json) — состояние текущей или ожидающей сессии согласования.
- [Artifact edit decision ledger](artifact-edit-decision-ledger.md) — журнал решений по правкам.
- [План реализации](../../plans/datacanvas-prompt-only-documentation-artifact-review-implementation-plan.md) — исходный scope реализации workflow.

## Граница

- Workflow работает только с проектной документацией и документальным сопровождением.
- Workflow не принимает продуктовые решения за владельца.
- Продуктовые утверждения в чате разрешены только как цитата или пересказ содержимого конкретного артефакта с ссылкой на источник.
- Любая правка продуктового смысла оформляется как предлагаемая правка документа и требует явного согласования владельца.
- Generated artifacts — автоматически созданные файлы — не редактируются вручную. Правка идет через источник, генератор и повторную проверку.
- Абсолютные локальные ссылки допустимы только в runtime chat — текущем ответе чата. В сохраняемых файлах используются только относительные пути репозитория.

## Правило Продолжения

После обрыва агент читает `artifact-review-session-state.json`, затем `artifact-edit-decision-ledger.md`, затем продолжает с `current_step`. Если `current_step` равен `awaiting_prompt`, новых открытых решений нет.
