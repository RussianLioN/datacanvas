# PROC-001: Принять Процесс 0.1.0

Статус: accepted
Дата: 2026-06-22
Целевая версия процесса: `0.1.0`

## Проблема

До Sprint 0 в репозитории нет управляемой системы процесса разработки DataCanvas.

## Причина Изменения

Продуктовую реализацию нельзя начинать без базовых правил ролей, артефактов, evidence, изменения процесса и приемки.

## Изменение

Создать стартовый набор process artifacts и принять `DataCanvas Delivery Process 0.1.0` как рабочий baseline.

## Метрика Успеха

G0/G1 artifacts существуют и связаны со sprint evidence.

## Rollback

Вернуть процесс к состоянию до принятия `0.1.0` можно удалением созданных process artifacts до первого принятого Sprint Review.

## Решение

Статус решения: accepted.  
Дата решения: 2026-06-22.  
Решающий владелец: Process Owner.

Accepted как bootstrap-изменение для запуска Sprint 0.
