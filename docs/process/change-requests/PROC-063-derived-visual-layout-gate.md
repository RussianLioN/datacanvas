# PROC-063 — Блокирующая Проверка Компоновки Визуальных Артефактов

ID: `PROC-063`
Статус: accepted
Статус решения: accepted
Дата: 2026-07-12
Владелец: Process Owner / QA Lead

## Причина

Визуальный BMC проходил действующие проверки, хотя текст нескольких блоков выходил за рамки и пересекал соседние области. Проверки подтверждали наличие структуры, минимальный размер шрифта, возможность открыть SVG и соответствие хэшей, но не измеряли компоновку готового результата.

## Принятое Правило

- Генератор визуального артефакта обязан до публикации рассчитать размещение текста и завершиться ошибкой, если содержимое не помещается при минимально допустимом размере шрифта.
- Профильный валидатор повторно проверяет готовый SVG или другой формат: границы текста, границы рамок, отсутствие пересечений, равномерность сетки и нахождение всех элементов внутри холста.
- Для PNG и PDF режим проверки создаёт свежий рендер из канонического визуального источника. Каждый переносимый формат проверяется отдельно отрицательным тестом на устаревший файл.
- PlantUML проверяется на ограничение длины строк, полноту блоков и пространственных связей. Если в репозитории появляется отдельный PlantUML-рендер, для него добавляется профильная проверка геометрии готового изображения.
- Исторические снимки остаются доказательством своего запуска, но не включаются в текущий acceptance manifest после изменения источника или генератора.
- Проверка хэша, существования или возможности открыть файл не заменяет проверку визуальной компоновки.

## Область Изменения

Правило относится к контуру проектной документации DataCanvas и не меняет продуктовый смысл Vision, BMC, пользовательских историй, требований, backlog или roadmap.

## Миграция

Текущий BMC перегенерирован. Для SVG добавлен расчет размещения, для SVG и PlantUML — блокирующий валидатор с отрицательными тестами, для PNG/PDF — свежая проверка рендера. Старые browser/PDF raster snapshots помечены как историческое evidence и исключены из актуального BMC-пакета.

## Проверка

```bash
npm run generate:bmc -- --check
npm run validate:bmc-visual
npm run validate:bmc-render-parity
npm run validate:bmc-package
npm run validate:bmc
npm run validate:universal-documentation-workflow
npm run validate:process-change-ledger
npm run validate:artifact-registry
npm run validate:artifact-hashes
npm test
```

## Откат

До слияния изменения можно удалить одним коммитом. После слияния откат выполняется отдельным PR. Откат не должен возвращать исторические снимки в актуальный acceptance manifest или заменять свежую проверку PNG/PDF копированием существующих файлов.
