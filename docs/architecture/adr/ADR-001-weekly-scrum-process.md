# ADR-001: Недельный Scrum По Умолчанию

Статус: accepted
Дата: 2026-06-22

## Контекст

Команда приняла решение адаптировать Scrum с недельными спринтами, с возможностью изменить cadence при необходимости.

## Решение

Использовать недельный спринт как default. Изменение длины спринта проходит через Process Change Request.

## Последствия

- Требуется строгий slicing backlog items.
- Sprint Review и Retrospective должны быть короткими и evidence-based.
- Повторяющийся spillover запускает процессный эксперимент или изменение cadence.
