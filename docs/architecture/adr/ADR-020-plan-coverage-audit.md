# ADR-020: Проверяемый Аудит Покрытия Плана

Дата: 2026-06-22
Статус: accepted

## Контекст

Активная цель требует выполнять план из `docs/plans/datacanvas-adaptive-scrum-implementation-plan.md`, а не подменять его локальными улучшениями. После нескольких процессных инкрементов нужен проверяемый способ видеть, какие разделы плана закрыты артефактами и gates, а какие остаются неполными.

## Решение

Добавить machine-readable audit `docs/process/audits/datacanvas-plan-coverage-audit.json`, человекочитаемый отчет и validator `scripts/validate-plan-coverage.mjs`.

Валидатор проверяет:

- audit соответствует JSON Schema;
- все 17 разделов исходного плана покрыты;
- каждый раздел существует в source plan;
- human-readable report содержит строку по каждому разделу;
- evidence paths существуют.

## Последствия

- Следующий инкремент выбирается из явных gaps, а не из памяти.
- Цель нельзя корректно считать завершенной, пока audit показывает `partial` или `not_started` по DoD-критичным разделам.
