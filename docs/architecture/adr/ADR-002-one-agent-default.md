# ADR-002: Один Агент По Умолчанию

Статус: accepted
Дата: 2026-06-22

## Контекст

DataCanvas стартует как AI-агент для генерации краткой презентации из входного пакета данных.

## Решение

DataCanvas v1 реализуется как один агент-оркестратор с инструментами. Multi-agent допускается только через отдельный ADR/PCR с измеримой причиной.

## Последствия

- Меньше сложность, прав доступа и трассировки.
- Все tool permissions должны быть явно описаны.
- Расширение агентной архитектуры требует evidence.
