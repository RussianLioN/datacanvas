# ADR-003: PresentationSpec Как Граница

Статус: accepted
Дата: 2026-06-22

## Контекст

LLM-часть не должна напрямую генерировать финальный HTML/PDF, чтобы сохранить проверяемость и детерминированность рендера.

## Решение

LLM генерирует только валидируемый `PresentationSpec`. Renderer детерминированно строит итоговый export из этой спецификации.

## Последствия

- `PresentationSpec` становится центральным контрактом.
- Renderer можно тестировать отдельно.
- Claims и visual structure трассируются до входных данных.
