# ADR-018: Валидация Реестра Артефактов

Дата: 2026-06-22
Статус: accepted

## Контекст

`artifact-registry.json` используется как управляемый индекс артефактов процесса, продукта, архитектуры, проверок и evidence. До этого он валидировался только как JSON по схеме, но схема не доказывала, что пути существуют, `ART-*` уникальны, а `sprint_id` связан с evidence-манифестом.

## Решение

Добавить `scripts/validate-artifact-registry.mjs` и включить его в `npm test`, CI и bootstrap checks.

Валидатор проверяет:

- соответствие `schemas/artifact-registry.schema.json`;
- формат и уникальность `ART-*`;
- отсутствие пропусков в последовательности `ART-*`;
- уникальность путей;
- существование каждого зарегистрированного пути;
- наличие `sprint-evidence-manifest.json` для каждого `sprint_id` из реестра.

## Последствия

- Новый артефакт без файла, evidence или корректного ID блокирует проверку.
- Реестр становится процессным gate, а не только справочным списком.
- При удалении или переименовании артефакта нужно обновлять registry и evidence вместе.
