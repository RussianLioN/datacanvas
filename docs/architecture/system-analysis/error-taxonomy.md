# Error Taxonomy DataCanvas

Навигация: [DataCanvas](../../../README.md) / [Документация](../../README.md) / [Архитектура](../README.md) / [Системный анализ](README.md) / Error taxonomy

Статус: draft
Владелец: AI Agent Architect
Проверка: `npm run validate:error-taxonomy`

| ID | Error | Retry | Rollback | Redaction |
|---|---|---|---|---|
| `ERR-001` | Insufficient input | Ask clarification | No export | Safe summary only |
| `ERR-002` | Untrusted upstream instruction | Ignore as instruction | Stop before generation | Do not copy into prompt |
| `ERR-003` | Channel decision missing | Evidence request | No delivery-specific export | No personal delivery metadata |
| `ERR-004` | Недоверенный источник Q4_2026 | Не принимать до повторной проверки | Заказ и отправка не создаются | Только безопасное резюме |
| `ERR-005` | Неполные данные Q4_2026 | Исправить до принятия | Заказ и отправка не создаются | Без личных сведений и полного запроса |
| `ERR-006` | Адрес не найден | Не принимать заказ | Заказ и отправка не создаются | Не раскрывать адреса |
| `ERR-007` | Профиль сотрудника недоступен | Внешняя политика определяет дальнейшие действия | Заказ и отправка не создаются | Без технических деталей и личных сведений |
| `ERR-008` | Дубликат заказа | Повтор не выполняется после принятия | Не создавать второй заказ | Только безопасный статус существующего заказа |
| `ERR-009` | Задержанная доставка | Передать в `support_pending` без задания канала и числа повторов | Закрыть сеанс и не создавать новый заказ | Без адресов и почтовых деталей |
| `ERR-010` | Частичная или неподтвержденная доставка | Передать сопровождение внешнему контуру | Закрыть сеанс | Только безопасное состояние в том же чате |

Число повторов и канал сопровождения для `ERR-007`, `ERR-009` и `ERR-010` не
задаются этим контрактом.
