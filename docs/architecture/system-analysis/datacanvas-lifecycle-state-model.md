## Состояния

`intake -> validation -> clarification -> normalization -> description -> approval -> render_export -> delivery_acceptance`

Состояние `approval` применяется только к диалоговому режиму в Лисе: пользователь после описания структуры выбирает изготовление презентации или редактирование структуры.

При запуске другим агентом DataCanvas после проверки достаточности и безопасности данных пропускает ручное подтверждение и переходит к подготовке презентации.

Для `CO-2026-001` — принятого изменения приоритета продукта — канал доставки файла принят: готовая презентация отправляется пользователю по электронной почте. Состояние `delivery_acceptance` закрывается после отправки файла и фиксации очищенного статуса доставки; при запуске другим агентом вызывающий агент получает статусы и сведения о результате.
