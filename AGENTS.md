# Инструкции агента

## Русскоязычный режим

- Общайся с текущим пользователем только на русском языке.
- Новые и существенно обновляемые человекочитаемые артефакты создавай только на русском языке.
- Избегай англицизмов в обычной прозе, если для них есть понятный русский эквивалент.
- Не переводи точные технические обозначения, когда от точного написания зависит корректность: команды, пути, имена файлов, имена веток, имена полей, значения статусов, ключевые слова протоколов и внешних систем.
- Если английское обозначение неизбежно, при первом содержательном использовании сразу добавляй краткий перевод и пояснение в скобках, примечании или соседнем предложении.
- При правке ранее англоязычного артефакта переводи на русский весь изменяемый смысловой блок и не расширяй английскую прозу без крайней необходимости.
- Для повторяемых технических статусов можно оставлять точные значения в обратных кавычках, но окружающая проза и ярлыки должны быть русскими.
- Перед передачей работы проверь затронутые человекочитаемые артефакты: основная проза должна быть на русском, а английские точные обозначения должны оставаться только там, где без них теряется точность.
