## Проверенные свойства

- Сохранены три листа, формулы и структура книги.
- На `Лист1` весь диапазон `J1:V1` подтверждён как одна группа общей
  формулы: мастер `J1` содержит `J2*$C$1`, а все ячейки диапазона имеют
  тот же `si`; `J2:V2` остаются исходными подытогами.
- Полный фактический ресурс взят из числового значения Excel
  `Итоговые ресурсы!B4=304.4` с допуском для двоичной погрешности; строка
  XML-кэша не является единственным смыслом значения. `B8` отдельно
  проверен и не принимается за полный итог. В манифесте `304.4` прямо
  отмечен как отображаемый итог.
- На листе `СОЗАВИСИМОСТЬ Q3_2026` текст строки изменён ровно на
  «Сообщения о статусе заказа в том же чате Лисы», ресурс строки сохранён
  равным `35`, а устаревшее упоминание PUSH отсутствует.
- Из `xl/workbook.xml` удалён `absPath`; авторы и содержимое комментариев,
  а также поля `creator`/`lastModifiedBy` в `core` обезличены общим правилом.
  Текст комментариев очищается при сохранении OOXML-структуры, поэтому
  защита не зависит от конкретного личного имени.

## Проверки и доказательства

Выполнены успешно после генерации:

```text
npm run validate:xlsx-backlog-2026-08-17
npm run validate:xlsx-backlog
npm run test:source-security
npm run validate:product-source-consistency
npm run validate:data-leakage
git diff --check
```

Дополнительно штатный генератор выполнен с внешним исходником, чей SHA-256
совпадает с закреплённым значением:

```text
npm run generate:xlsx-backlog-2026-08-17 -- --source <external-owner-xlsx> --expected-original-sha256 722a604831b2b589ac9aea99dd8cccd80090d9e166a2adc40b284d0bdb147bf1
```

Профильные отрицательные проверки подтверждают отклонение возврата локального
пути, неочищенных автора и текста комментария, неочищенных полей `core`,
потери или разрыва общей формулы `J1:V1`, удаления формул, неверного источника
общего итога, старого статуса PUSH и изменения ресурса строки.
