## Локальный Архив Документации

- [Полный ZIP-архив главной цепочки DataCanvas](documentation-archive/datacanvas-main-documentation.zip?raw=1) — внутренний пакет с ограниченным доступом, всеми основными файлами действующей цепочки и восемью дополнительными материалами, включая руководство и подготовленный CSV для импорта пользовательских историй в Jira; после распаковки доступна автономная навигация.

Архив обновляется только командой `npm run generate:documentation-archive` и проверяется командой `npm run validate:documentation-archive`.

Не хранить здесь секреты, необработанные трассы, приватные данные или временные локальные файлы.
